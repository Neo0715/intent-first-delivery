## 6. 假设清单

> 用户没明说、但我必须假设才能推进的项。**每一项都要标状态。**

| # | 我的假设 | 如果假设错了会怎样 | 状态 |
|---|---|---|---|
| 1 | | | `[待用户确认]` |
| 2 | | | `[用户已确认]` |

**处理规则**：

- 所有 `[待用户确认]` 项必须在进入 ③ 之前清零，或由用户明确声明「接受该风险」
- 用户说「你看着办」不等于确认 —— 那等于把风险转移给了你。**不要把同一个问题再问一遍**：把选项收敛成「要 A 效果还是 B 效果」，给出我的建议，写成「我按 X 做，除非你说不」，并在下方变更记录里注明「用户授权自行决定」
